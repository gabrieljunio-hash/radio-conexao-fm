Atendimento

A Conexão FM é um projeto independente. O contato é feito diretamente pelo WhatsApp, sem formulário de cadastro no site.

Para indicar uma nova emissora, você também pode usar a página Indicar uma rádio. Antes de incluir uma estação, os links enviados são conferidos.

Ao abrir o WhatsApp, você poderá revisar a mensagem antes de enviá-la. O tratamento das informações após o envio segue as políticas do próprio WhatsApp.
